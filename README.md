## 本轮优化了什么

1. 不用宽口径阀门贸易和搜到的商户数量证明最佳国家；三个入选国是验证范围。
2. 用逐家功能、开放来源与渠道条件组织P队列；原A/B匹配分仅保留作历史轨迹。
3. 读取受控V11，保留已有PN16尺寸和部分Kv/流量表，新增产品资料卡及12项补证清单，不把压力检验当性能/准入认证。
4. 重写4封资料请求负担较高的首封，同步译文；20封均保留不同的真实商业问题。
5. 新增资格信息、回复分支、十项报价条件、小批复盘及私有事件日志空模板。
6. 统一从当前输入生成TXT、MD、CSV、Word与Excel，临时构建及失败回滚；历史输入、快照和当前数据分开。

首批研究队列为V01/V02/V04/M01/M02/U01；M05/M06/U03/U06暂缓。6家试验分配及复盘阈值是资源控制建议，不是成功率或行业基准。资料不足的事项保持未知，不伪造成本、利润、客户订单或购买意愿。

## 一条命令取文件

```bash
python3 scripts/reproduce.py
```

Python 3.10及以上，仅用标准库。默认复现v2至outputs/latest，生成完整ZIP；不会联网或改变核验日期。取原版用 `python3 scripts/reproduce.py --version v1`。

从当前输入重建全部格式用 `python3 scripts/build_current.py`，需文档、表格和PDF运行时；只导出文字可加 `--text-only`。生成不等于新研究，新生成文件默认等待视觉验收。依赖、验收和发布见[生成说明](docs/reproduction.md)。
