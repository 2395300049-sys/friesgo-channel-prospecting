## 一条命令取出全部材料

克隆后运行，Python 3.10及以上，仅用标准库：

```bash
python3 scripts/reproduce.py
```

在 `outputs/latest/` 取得本次全部文件和压缩包，校验文件哈希与20家公司对应关系。该命令是**复现已核验快照**，不会重新联网查客户，也不会把核验日期改成今天。

在具备 Codex 表格运行时及 `python-docx` 的环境，可运行 `python3 scripts/reproduce.py --rebuild` 从主数据重新生成 Word、客户 Excel和一页打印 Excel；如有 LibreOffice，还会重新输出打印 PDF。没有这些依赖时，仍可使用上面的无依赖快照命令。详见[生成说明](docs/reproduction.md)。

## 这次研究结果的范围

本次比较越南、马来西亚、阿联酋、哈萨克斯坦、乌兹别克斯坦、沙特、印度尼西亚、德国。首批20家为越南7家、马来西亚6家、阿联酋7家，11家A组、9家B组；优先级是研究联系顺序，不是成交概率。已找到6个分销网络，未证明它们均为单一实体批发市场。

贸易背景是2023—2025年中国报告方HS848180对八国的出口，不能当成平衡阀专属市场规模。2026年6—9月查询为空，实际最新可用月未确认。公司产品在售、历史项目、采购权限、当前RFQ分别记录；本次未确认采购权或当前RFQ，未发送开发信。

公开业务联系方式与公司自述均附来源。`evidence/` 保存贸易查询、联系来源索引、原始核读文件的哈希目录及检查记录；第三方网页全文、登录材料、本机路径、实际业务员操作记录不进入公开仓库。原内部产品母表未整体公开，仓库保留本次采用的产品事实与证据限制摘录。
