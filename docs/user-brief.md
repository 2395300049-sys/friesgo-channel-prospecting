# 用户需求与最终验收要求

## 业务故事

用户先要求丢开旧开发思路，重新按以下逻辑执行：

> 我是卖菜的，我先把菜卖给菜市场，然后菜市场把菜卖给饭店，当然还有一些散户也会去菜市场买菜。

随后明确阀门业务的对应关系：

> 我要先找到海外的“菜市场”，再找到里面卖阀门的商户，把阀门卖给他们，由他们卖给下游客户。

这个类比需要补足的地方是：通常商户或进口分销公司才是交易和选品主体；“市场”是发现商户的渠道或聚集网络，不必是向所有商户统一采购的组织。饭店对应承包商、安装商、设备配套及楼宇等下游客户；散户说明渠道可能同时有零售，但本轮主要看转售和工程渠道。

用户接着提出：先调研市场，再决定把菜卖给哪个“菜市场”。因此执行顺序是产品边界 → 市场比较 → 渠道网络 → 商户 → 联系岗位 → 逐家开发与跟进。

## 研究与销售材料

用户的明确要求：

- 每一步都有足够有说服力的依据。
- 最终需要20个客户，提供详细联系方式和对应项目的开发信。
- 禁止每一篇开发信类似。
- 确认以手动平衡阀、自力式压差控制阀、自力式流量控制阀三类为主。
- 最终整理为一个可编辑Word文件。

没有20个正在采购的项目证据时，不能杜撰。交付采用具名历史项目及其实际供货边界，或明确标记的产品/应用场景，并说明未核实当前RFQ。

## 打印工作表的最终修改

用户最初要求横版工作表，竖向仅公司名字，横向为网站、WhatsApp等社媒渠道，业务员做一步记录一步。制作中曾提出每页5家分4页，用户随即修正：

> 我希望一张打印下，简约一点就是，主要是方便工作。

**最终采纳：1张A4横版，20家公司各占一行。首列仅公司名称；横向网站、邮箱、WhatsApp、LinkedIn、Facebook/IG、Zalo/微信、电话、下次跟进/备注；记录格空白，业务员手写日期与动作。**

顶部仅留业务员、记录周期和一行简短记录说明。表格不预填已联系，不为了提供详细账号挤占手写空间；真实联系详情另看客户档案。Excel为可编辑模板，PDF为直接打印版。
