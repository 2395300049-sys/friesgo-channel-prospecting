# 从市场到商户的完整工作方法

本页保存市场到商户的发现方法。当前行动判断与销售闭环以[项目审核](project-audit-2026-10-23.md)和[推进手册](sales-playbook.md)为准；下文v1的A/B与各国配额只供追溯，不能覆盖v2的P队列。

当前思路修正见[二次验证](method-revalidation-2026-10-23.md)：市场筛选与客户访谈循环更新；产品资料补证与采购路径询问并行；能转售、有选品权、来源开放、供货可行和交易有收益分别验证。完整顺序是工作路线，不能解释为必须先完成所有国家研究与全系列技术文件才能了解一个商户。

## 产品决定查找范围

先读产品资料，列功能、目录参数、测试覆盖及不能承诺的内容。把可服务的水系统工况翻译成客户语言，避免把手动平衡、支路压差、自力恒流、电动PICV和普通减压阀混为一类。产品事实见 [产品边界](product-boundaries.md)。

## 先比较市场 再分配客户名额

本案例事先比较8国，覆盖热带冷冻水、海湾区域供冷、中亚供热和欧洲成熟暖通渠道。可复用的是比较方法，8国和7/6/7分配并非永久结论。

逐市场记录：实际应用证据；进口/分销路径；可验证商户和联系方式；新增供应商障碍；反证；尚缺资料；最小验证动作及退出条件。把事实、推断、缺口分开。

贸易数据仅作背景。保持报告方、流向、HS版本、年份、FOB/CIF、币种和单位一致；披露缺失数据及镜像统计差异。HS848180不单独识别三类平衡阀，不以此计算专属市场规模、客户订单、利润或成交率。空响应不是零。报告日期与数据年度分别标明。

本轮选择越南、马来西亚、阿联酋，是因为取得了足够的相关渠道和联系证据；马来西亚2025宽口径出口下降，仍因具体平衡阀/组件渠道入选。中亚有供热背景，本轮未完成同等深度的商户与准入审核，因此不能说其需求较弱。完整取舍见 [调研报告](market-research-2026-10-23.md)。

## 识别菜市场和里面的商户

先找行业目录、商户聚集地点、官方展会/行业平台作为发现入口，再返回公司官网核角色、产品、项目及联系。可以直接在已选分销渠道内查找官网，不强求每家来自同一目录。

有证据才称实体市场；分散办公室和仓库应称分销网络。展会主办方、平台、目录条数和终端业主不算采购客户。品牌办公室、制造商、无外采缺口的自有渠道、同集团分支及同公司多个网站需要单独判断或去重。

商户入选同时满足：海外身份、进口/分销/配套供应角色、相关功能、公开可用入口、明确首封验证问题。油压counterbalance valve不能因检索词相近进入暖通平衡阀名单。20个独立账户不足时继续补证，不拿分支凑数。

## 逐家核实联系路径

记录官网、业务邮箱、电话、地址、具名联系人及公开职务、应转岗位、备用路径、产品/联系/项目来源和核验日期。只用可证实的公开商业入口，不推测邮箱。销售联系人或Director不自动等于采购决策人；通用邮箱不叫采购邮箱。

官网明确WhatsApp/Zalo/微信或有对应链接才认定该即时渠道。LinkedIn公司页不是采购个人。地址、电话、独家代理冲突逐条保留采用理由，访问失败与已核来源分开。DNS/MX记录不证明投递成功或邮箱归属。

## 每封信都提出独立商业问题

由公司事实、合适产品功能、合作障碍推导一个容易回答的问题。可用方向包括允许新增来源、缺少的SKU、仓配常用规格、维修安装长度、组件BOM选型权、技术预审资料、独家代理范围、区域供冷配套及海外供应资格。不是把同一封模板替换公司名。

历史项目注明年份和实际披露品类；仪表或流量开关供货不能改写成平衡阀供货，Control Valve也不能直接等同本品。不把历史项目当当前RFQ。没有具名项目则用已核产品/服务和明确应用场景。

英文首封不超过150词，不首附通用公司宣传册，结尾一个低负担CTA。越南客户默认越南语，并留英文母稿和中文译文；其他客户默认英文加中文。保持供应商身份，功能匹配先于报价、替代或认证承诺。

对20封信做机械相似度提示，再人工确认事实、商业问题及下一步不同。相似度低不证明内容可靠；共同品牌签名不算不合格重复。

## 业务员记录和跟进

操作表只放一页：公司名为首列，渠道横向，20行空白记录格。每格可记“日期＋查/加/发/回”，最后一列记下次日期或事项；具体账号看客户档案。不要把可用渠道预填成已操作。

本轮v2建议V01/V02/V04/M01/M02/U01共6家做小批验证，发送前先核资料和入口。取得负责人转介、允许新增来源、一个真实回路/BOM或资料清单后再推进。P队列为研究行动顺序，不是需求确认；后续研究依当次证据分配。

实际发送日为T0。若5个工作日无回应，使用一个公开备用入口核部门；再过7个工作日无有效信息则暂停。对方明确无兴趣、拒收或代理不允许时停止。自动回复只表明系统回执，不代表采购兴趣。

收到回应后补真实主体、直接进口、选品权、规格工况、数量、批准文件、目的地、付款和交期。资料齐全后才报价。仓库不自动发送邮件、提交表单或创建提醒。

## 交付与验收

资料主数据、市场模型、来源和所有输出保持同一客户ID。每家核对联系、功能、项目状态、主题及信件。Word需可编辑、来源可点、中文和越南语正常、逐页无截断。Excel可编辑；打印PDF必须1页A4横向、20家公司全在同页、文字与网格清晰。快照和联网更新采用不同日期，不覆盖已验收历史。
