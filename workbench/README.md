# FriesGo 本地客户开发工作台 0.2

在本机管理客户、项目机会、双语开发信与跟进记录，打开浏览器即可使用，无需 ChatGPT 或 Apple 登录。服务只监听 `127.0.0.1`，数据保存在本机 SQLite。

## 启动

需要 Node.js 24 或以上及 npm。首次安装依赖需要联网；构建完成后，客户管理、历史查询和 Word 导出在本机执行。

```bash
cd workbench
npm ci
npm run check
npm run build
npm start
```

打开 **http://127.0.0.1:5173**。macOS 会自动打开浏览器，也可双击本目录的 `启动工作台.command`。其他系统可手动打开网址。

停止服务：`npm stop`，或在 macOS 双击 `停止工作台.command`。关闭浏览器不会停止服务。再次使用执行 `npm start`；电脑重启后也需要重新启动服务。重复启动不会创建第二个实例。

不自动打开浏览器：`npm start -- --no-open`。依赖变化时重新执行 `npm ci`；源码更新后执行 `npm stop`、`npm run build`、`npm start`。重建不会清除 `data/`。

## 已包含

- 客户查询、国家和阶段筛选、联系人登记、官网及已核实社媒入口。
- 项目与多个客户关联，区分建设阶段、采购状态、预计采购窗口及其依据。
- 双语开发信版本、中文对照、回复话术和可替换签名。
- 实际沟通时间线、到期任务及下一步安排。
- 全局与单家客户的操作历史，按时间、客户、类型、动作和关键词筛选，展开对照修改前后。
- 开发信复制时的草稿快照，以及登记实际联系时冻结的双语正文。复制、生成文件与发送分别记录。
- 研究 JSON 导入、批次去重、完整 Word 导出及包含历史的 JSON 备份。

旧日志保留其原始信息；启用历史前没有保存的修改内容无法补回。普通保存与其历史记录在同一事务提交，重复保存、过期版本和失败写入不会生成成功修改记录。导入保留人工负责人、跟进日期和停止联系状态。

## 数据与备份

本目录 `data/friesgo.sqlite` 是运营数据库；`data/service.json` 与 `data/service.log` 是本地启动状态和日志。它们全部被 Git 忽略。更新本地代码前，先停止服务并备份整个 `data/` 目录；也可在网页内下载 JSON 备份。

`local/dist/` 仅存构建产物。数据目录独立于构建目录；可通过环境变量 `FRIESGO_DATA_DIR` 指定另一绝对目录。填写后的记录、买方回复、签名及运营备份只在私有副本保存。

公开的 `app/seed.json` 是2026年10月24日整理的 **24家公司初始研究与草稿**，包括24组中外文开发信和13类回复话术，不包含真实联系日志、买方回复、签名或运行中的数据库。部分联系方式仍标记待复核；原计划日期不代表发送。该初始组合与仓库根目录的20家渠道候选池是独立资料，编号和角色不互相覆盖，也不表示24家均满足渠道准入条件。

FriesGo Global 的供应商定位及产品事实边界沿用仓库规则；公开研究不证明当前采购需求。未启用自动发信、自动项目监测、多人登录或手机局域网访问。

## 验证

```bash
npm run check
npm run build
npm test
```

集成测试启动独立临时数据库与随机本机端口，验证历史快照、版本冲突、事务回滚、导入幂等、项目关联和导出，不读写你的日常数据库。

## 源码位置

`app/` 保存界面及业务逻辑；`local/` 保存 SQLite 适配、本机 HTTP 服务和构建/启动脚本。构建时把原业务层的 `cloudflare:workers` 存储接口映射到 `local/database.ts`；运行时不依赖 Cloudflare 或 Sites，不包含云端站点配置或认证凭据。
